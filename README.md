# Portfolio Site

This repository holds the code for my personal website, [chadglazier.com](https://chadglazier.com). 

## Acknowledgements

- Many of the UI elements were borrowed and/or heavily inspired by [Skyrim](https://en.wikipedia.org/wiki/The_Elder_Scrolls_V:_Skyrim) (2011) by Bethesda. The original asset files were pulled from [a page on Nexus mods](https://www.nexusmods.com/skyrimspecialedition/mods/82169) and from the Figma projects linked in [this YouTube video](https://youtu.be/0N87f5wfxr0?si=45zO9s2bKP16Lp1c&t=656).

- The solar system in the background uses textures from [Solar System Scope](https://www.solarsystemscope.com/textures/).
